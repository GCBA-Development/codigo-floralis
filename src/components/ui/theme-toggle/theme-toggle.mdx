# ThemeToggle

Botón de ícono que cicla el tema claro, oscuro y (si el provider lo habilita) del sistema, o alterna solo claro/oscuro con `mode="toggle"`. Vive en `codigo-floralis/theme` y necesita `FloralisProvider` (o el `ThemeProvider` de next-themes) y la peer dependency `next-themes`.

## Cuándo usarlo

- En la barra de navegación o en el menú de preferencias.
- Cuando el usuario tiene que poder elegir el tema manualmente.

## Cuándo NO usarlo

- Si la app no soporta modo oscuro.
- Para leer o forzar el tema por código: usá `useTheme()`.

## Props clave

`mode` (`cycle` default o `toggle`), `label` (nombre accesible base, default "Cambiar tema"), `themeLabels` (`{ light, dark, system }`, textos con los que se anuncia el próximo tema) y las props de `Button` (`variant` default `ghost`, `size` default `icon`, `className`...).

## Accesibilidad

- El nombre accesible anuncia la próxima acción: "Cambiar tema (siguiente: oscuro)". El ícono muestra el tema actual.
- Es un `button`: Enter y Espacio lo activan.
- Hasta que el cliente hidrata renderiza un botón deshabilitado del mismo tamaño: sin mismatch de hidratación ni salto de layout.

## Do / Don't

**Do**

- Ponelo en un lugar fijo y predecible.

**Don't**

- No lo uses fuera de un provider de next-themes.
