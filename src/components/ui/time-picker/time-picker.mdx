# TimePicker

Campo de hora (`hh:mm`) nativo, con el estilo de la librería. `TimePickerCustom` es un alias deprecado.

## Cuándo usarlo

- Horarios de inicio/fin, turnos.

## Cuándo NO usarlo

- Fechas: no hay `DatePicker` todavía.
- Duraciones en minutos: usá `Input type="number"`.

## Props clave

`label`, `description`, `error`, `required`, `variant` (`outline | modern | glass`). Props de `input` (`min`, `max`, `step`, `value`). `helperText` quedó como alias deprecado de `description`.

## Accesibilidad

- Usa `input type="time"`: el teclado y los lectores usan el control nativo del sistema.
- Label y error asociados por `Field`.

## Do / Don't

**Do**

- Validá rangos con `min`/`max`.

**Don't**

- No lo uses para fechas completas.
