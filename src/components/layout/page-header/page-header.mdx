# PageHeader

Encabezado de página: título (`h1`), subtítulo, etiqueta superior y acciones.

## Cuándo usarlo

- Parte superior de cada página, una vez.

## Cuándo NO usarlo

- Títulos de secciones internas: usá `CardTitle` o `Text variant="header"`.

## Props clave

`title`, `subtitle?`, `eyebrow?` (etiqueta chica sobre el título), `actions?` (uno o varios `Button`, en un fragment si son varios; van arriba a la derecha, alineados con el título).

## Accesibilidad

- Renderiza el único `h1` de la página.

## Do / Don't

**Do**

- Un título que describa la página, no el sitio.

**Don't**

- No lo repitas en la misma vista.
