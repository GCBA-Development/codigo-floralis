# PageHeader

Encabezado estándar de página: `[start] [título + subtítulo] [end]`, con el título a la izquierda.

## Cuándo usarlo

- Parte superior de cada página, una vez.

## Cuándo NO usarlo

- Títulos de secciones internas: usá `CardTitle` o `Text variant="header"`.

## Props clave

- `title`, `subtitle?` (texto o contenido, ej. una línea con un link).
- `start?`: a la izquierda del título, alineado con el título (no con el subtítulo). Para botón volver, ícono o badge. Si no se pasa, no deja hueco.
- `end?`: a la derecha. Uno o varios `Button` (en un fragment). En mobile baja debajo del título.
- `size?`: `md` (default, pantallas de gestión) o `lg` (portadas), con `eyebrow?` solo en `lg`.

### Deprecado

`actions` es alias de `end` (si se pasan ambos, gana `end`) y `size="compact"`/`"large"` son alias de `md`/`lg`. Se quitan en una próxima major.

## Accesibilidad

- Renderiza el único `h1` de la página.

## Do / Don't

**Do**

- Un título que describa la página, no el sitio.

**Don't**

- No lo repitas en la misma vista.
